# Code of conduct

Wigo Studio welcomes constructive participation from artists, developers, and
researchers. Be respectful, specific, and generous when discussing work.

Unacceptable behavior includes harassment, discrimination, threats, deliberate
intimidation, sexualized attention, doxxing, sustained disruption, or publishing
someone else's private information. Technical disagreement is welcome; personal
attacks are not.

Maintainers may edit or remove contributions and restrict participation when
needed to protect the community. Report conduct concerns privately through the
repository's security contact. Reports will be reviewed fairly and kept as
confidential as practical.

This code applies in repository spaces and when someone is representing the
project elsewhere.
